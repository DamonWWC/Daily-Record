## 一、跨平台迁移：.NET 8 / WPF → .NET 10 / Avalonia UI

### 1.1 迁移背景与技术选型

原系统基于 WPF 构建，仅能运行于 Windows 平台。为满足轨道交通行业国产化替代要求（银河麒麟 V10 UKUI 桌面环境），需要将整个客户端迁移至跨平台框架。

**选型对比**：

| 维度 | WPF | Avalonia UI | MAUI |
|------|-----|------------|------|
| 跨平台 | ❌ 仅 Windows | ✅ Win/Linux/macOS | ⚠️ 移动端为主 |
| XAML 兼容性 | 原生 | 高度兼容（自有方言） | XAML 差异较大 |
| Linux 桌面成熟度 | — | ✅ 生产级 | ❌ 不支持 |
| .NET 10 支持 | — | ✅ 完全支持 | ✅ |

最终选择 **Avalonia UI 11.3.9 + CommunityToolkit.Mvvm + .NET 10** 的组合。

### 1.2 双平台入口分离

## 二、YARP 反向代理架构

### 2.1 架构设计

客户端进程内嵌一个完整的 ASP.NET Core Web 应用（`WebApplication.CreateSlimBuilder`），监听 `localhost:{ProxyPort}`，同时承担两个角色：

1. **YARP 反向代理**：将 CEF 浏览器和原生代码的请求路由到对应车站/服务器后端
2. **Minimal API 本地桥接**：提供 `/ClientInternal/*` 端点供 H5 页面调用原生功能

```csharp
// MicsClient/App.axaml.cs → SetupProxy()

private static void SetupProxy()
{
    var builder = WebApplication.CreateSlimBuilder();
    var port = builder.Configuration.GetValue<int>("ProxyPort");
    builder.WebHost.ConfigureKestrel(options => options.ListenAnyIP(port));

    // 跨域（无限制策略）
    builder.Services.AddCors(options =>
        options.AddPolicy("MicsPolicy", b => b.AllowAnyOrigin()));

    // ──── YARP 反向代理 ────
    builder.Services.AddReverseProxy()
        .LoadFromMemory(
            ProxyConfigurations.GetRouteConfigs(),
            ProxyConfigurations.GetClusterConfigs(port))
        .LoadFromConfig(builder.Configuration.GetSection("ServerProxy"))
        .AddTransforms(transforms =>
        {
            transforms.AddRequestTransform(async context =>
            {
                var transform = context.HttpContext.RequestServices
                    .GetRequiredService<ClientProxyHeaderTransform>();
                await transform.ApplyAsync(context);
            });
        });

    // ──── 本地 Minimal API ────
    builder.Services.AddLocalService();

    var app = builder.Build();
    app.UseCors();
    app.UseLocalService();     // 本地 API
    app.MapReverseProxy();     // 反向代理
    app.RunAsync();
}
```

### 2.2 多站点路由配置

`ProxyConfigurations` 动态生成 YARP 路由规则，支持三类路由优先级：

```csharp
// MicsClient/Common/ProxyConfigurations.cs

public static IReadOnlyList<RouteConfig> GetRouteConfigs()
{
    var list = new List<RouteConfig>();
    var hosts = HostConfigsReader.ReadHostConfigs();

    // ① 车站级路由: /XDZ/{**remainder} → XDZ 集群
    foreach (var host in hosts)
    {
        list.Add(new RouteConfig()
        {
            RouteId = host.LocationName,
            ClusterId = host.LocationName,
            Match = new RouteMatch()
            {
                Path = $"/{host.LocationName}/{{**remainder}}",
                Headers = [new RouteHeader()
                {
                    Name = Header.RequestType,   // "mics-request"
                    Mode = HeaderMatchMode.NotExists  // 排除本地请求
                }]
            }
        }.WithTransformPathRemovePrefix($"/{host.LocationName}"));

        // ② 服务器级路由: /MICS-XDZ-SCADA/{**remainder} → 特定服务器
        list.Add(new RouteConfig() { RouteId = host.ServerName, ... });
    }

    // ③ 本站默认路由（兜底）
    list.Add(new RouteConfig()
    {
        RouteId = "LocalStation",
        ClusterId = GetLocationName(config.LocationId),
        Match = new RouteMatch() { Path = "{**catch-all}", ... }
    });

    // ④ 内部服务路由（带 mics-request: local 头的请求 → 本地 API）
    list.Add(new RouteConfig()
    {
        RouteId = "InternalRoute",
        ClusterId = "InternalService",
        Match = new RouteMatch
        {
            Path = "{**catch-all}",
            Headers = [new RouteHeader()
            {
                Name = Header.RequestType,
                Values = ["local"],
                Mode = HeaderMatchMode.ExactHeader
            }]
        }
    });

    return list;
}
```

### 2.4 请求头加密注入

所有经 YARP 转发的请求统一注入加密身份头，确保后端可识别请求来源：

```csharp
// MicsClient/App.axaml.cs

public class ClientProxyHeaderTransform : RequestTransform
{
    public override async ValueTask ApplyAsync(RequestTransformContext context)
    {
        context.ProxyRequest.Headers.Add(Header.Console,
            ClientRequestHelper.GetUrlEncodeString(session.ConsoleName));
        context.ProxyRequest.Headers.Add(Header.OperatorId,
            ClientRequestHelper.GetEncyptContent(session.OperatorId));     // DES 加密
        context.ProxyRequest.Headers.Add(Header.OperatorName,
            ClientRequestHelper.GetUrlEncodeString(session.OperatorName)); // Base64URL 编码
        context.ProxyRequest.Headers.Add(Header.Session,
            ClientRequestHelper.GetEncyptContent(session.SessionId));      // DES 加密

        // 请求体 SHA256 签名追踪
        if (context.ProxyRequest.Content != null)
        {
            var body = await context.ProxyRequest.Content.ReadAsStringAsync();
            if (!string.IsNullOrEmpty(body))
            {
                var pretracking = SHA256.GetSha256(body, session.ConsoleName);
                context.ProxyRequest.Headers.Add(Header.Tracking,
                    ClientRequestHelper.GetEncyptContent(pretracking));
            }
        }
    }
}
```

### 3.2 连接基类：Polly 弹性重试 + 状态管理

`IceConnectionBase` 是所有 ICE 连接的抽象基类，提供统一的连接生命周期管理：

```csharp
// Server/ICE/MicsClient.Server.IIceConnection/IceConnection.cs

public abstract class IceConnectionBase
{
    public event Action<string>? OnConnected;
    public string CurrentConnectString { get; protected set; }

    // 线程安全的连接状态（Interlocked 原子操作）
    public ConnectState State
    {
        get => (ConnectState)state;
        protected set
        {
            if ((int)value != state)
            {
                Interlocked.Exchange(ref state, (int)value);
                if (value == ConnectState.Connected)
                    OnConnected?.Invoke(CurrentConnectString);
            }
        }
    }
    private int state = (int)ConnectState.DisConnect;

    protected abstract Task Connect(CancellationToken token);

    // Polly 无限重试 + 线性退避
    public async Task TryConnection()
    {
        if (State == ConnectState.DisConnect)
        {
            var retry = new ResiliencePipelineBuilder()
                .AddRetry(new RetryStrategyOptions
                {
                    BackoffType = DelayBackoffType.Linear,
                    MaxRetryAttempts = int.MaxValue,  // 永不放弃
                    MaxDelay = TimeSpan.FromMinutes(5),
                    Delay = TimeSpan.FromSeconds(1),
                }).Build();

            await retry.ExecuteAsync(async token => await Connect(token));
        }
    }

    // 重连触发
    protected void ReConnection()
    {
        if (State == ConnectState.Connected)
        {
            State = ConnectState.DisConnect;
            _ = TryConnection();
        }
    }

    // 网络可达性探测（多网卡场景下选择可达的本地 IP）
    protected static string GetLocalEndPointHost(string targetHost, int targetPort, int timeoutMs = 1000)
    {
        var localIPs = HostHelper.GetLocalIPAddresses()
            .Where(ip => ip.AddressFamily == AddressFamily.InterNetwork);
        foreach (var localIP in localIPs)
        {
            if (CanConnect(localIP, serverip, targetPort, timeoutMs))
                return localIP.ToString();
        }
        return "";
    }
}
```

### 3.4 报警接口实现：服务发现 + 多主机故障转移 + 回调注册

以 `AlarmInterface` 为例，展示完整的 ICE 连接流程：

```csharp
// Server/ICE/MicsClient.Server.IceConnection.Cd/Interfaces/AlarmInterface.cs

public sealed class AlarmInterface : IceConnectionCd, IAlarmInterface
{
    private IAlarmOperatorPrx prx;      // ICE 代理对象
    private string callbackId;
    private Channel<AlarmUnitList> alarmReciveChannel;  // 报警数据管道

    public AlarmInterface(ISystemNameInterface systemName, ...)
    {
        alarmReciveChannel = Channel.CreateUnbounded<AlarmUnitList>();
        // 监听服务名变更 → 触发重连
        systemName.AddCallback(new SystemNameCallback
        {
            AgentApplicationType = AgentApplicationType.AppTypeAlarmAgent,
            UpdateConfigAction = (_) => ReConnection()
        });
    }

    // 连接流程：服务发现 → 多主机逐个尝试 → 注册回调
    protected override async Task Connect(CancellationToken token)
    {
        State = ConnectState.Connecting;
        var location = configuration.GetValue<int>("MicsConfig:Location");

        // ① 服务发现：通过 SystemName 服务查询目标地址
        var config = await systemName.QueryServiceConfigExAsync(
            location,
            AgentApplicationType.AppTypeAlarmAgent,
            AgentIceServiceType.SvrTypeAlarmService);

        // ② 多主机故障转移：遍历所有 adapterHost
        foreach (string hoststr in config.adapterHost.Split(','))
        {
            var str = $"{config.identifyName}:tcp -h {hoststr} -p {config.adapterPort}";
            try
            {
                var p = ic.stringToProxy(str);
                prx = IAlarmOperatorPrxHelper.checkedCast(p);
                CurrentConnectString = str;
                // ③ 注册回调
                await RegisterCallBack();
                State = ConnectState.Connected;
                return;  // 连接成功，退出
            }
            catch (Exception ex)
            {
                logger.Error($"连接失败[{str}]", ex);
                // 尝试下一个主机
            }
        }
        throw new Exception("所有IP均无法连接");
    }

    // 回调注册：创建本地 ObjectAdapter 接收服务端推送
    private async Task RegisterCallBack()
    {
        var callbackobj = new AlarmUpdator(CurrentConnectString, ProcessAlarms);

        if (adapter is null)
        {
            // 创建回调适配器，绑定到可达的本地 IP
            adapter = ic.createObjectAdapterWithEndpoints(
                "AlarmUpdateCallBack",
                $"tcp -h {GetLocalEndPointHost(host, port)}");
            adapter.add(callbackobj, Ice.Util.stringToIdentity("AlarmUpdateCallBack.Receiver"));
            adapter.activate();
        }

        var callback = IAlarmReceiverPrxHelper.uncheckedCast(
            adapter.createProxy(Ice.Util.stringToIdentity("AlarmUpdateCallBack.Receiver")));
        callbackId = await prx.RegisterAsync(callback);

        // 请求全量报警
        await prx.requestAllAlarmAsync(callbackId);

        // ④ 心跳保活：3秒间隔检测回调连接存活
        Task.Factory.StartNew(async () =>
        {
            while (true)
            {
                await Task.Delay(3000);
                try
                {
                    var res = await prx.checkCallbackAliveAsync(callbackId);
                    if (res != 1) break;  // 心跳失败 → 退出循环
                }
                catch (Exception ex) { break; }
            }
            RegisterCallBack();  // 重新注册
        });
    }

    // 回调接收：ICE 推送 → Channel 写入
    private async Task ProcessAlarms(long count, List<AlarmUnit> alarms)
    {
        await alarmReciveChannel.Writer.WriteAsync(new AlarmUnitList
        {
            IsReconnected = isReconnected,
            Alarms = alarms
        });
    }
}
```

## 四、WebSocket 双通道通信架构

### 4.1 双通道设计

系统存在两个方向的 WebSocket 通道：

| 通道 | 方向 | 端点 | 用途 |
|------|------|------|------|
| **本地通道** | H5 ↔ Native | `ws://localhost:{Port}/ClientInternal/notification` | H5 组态页面与原生客户端双向通信 |
| **远程通道** | Server ↔ Client | `ws://server:{Port}/alarm/subscribe` 等 | 服务端推送报警/设备数据/事件到客户端 |

### 4.2 客户端 WebSocket：Polly 重连 + Pipe 读取 + Channel 解耦

`MicsWebsocketClient` 是客户端通用 WS 连接管理器：

```csharp
// SharedLib/MicsClient.SharedWebModel/Helpers/MicsWebsocketClient.cs

public class MicsWebsocketClientImpl : IMicsWebsocketClient
{
    public Channel<WebSocketCommand> SendChannel { get; }   // 发送管道
    public Channel<WebSocketCommand> ReceiveChannel { get; } // 接收管道

    public async Task ConnectAsync(string url)
    {
        // Polly 无限重试 + 线性退避 + 最大间隔 30s
        var retry = new ResiliencePipelineBuilder()
            .AddRetry(new RetryStrategyOptions
            {
                BackoffType = DelayBackoffType.Linear,
                MaxRetryAttempts = int.MaxValue,
                MaxDelay = TimeSpan.FromSeconds(30),
                Delay = TimeSpan.FromSeconds(1),
            }).Build();

        await retry.ExecuteAsync(async token => await StartConnectAsync(token));

        StartSendMessage();   // Channel Reader → WebSocket.SendAsync
        StartReciveMessage(); // WebSocket.ReceiveAsync → Pipe → Channel Writer
        StartHeartBeat();     // 15s 无心跳 → 触发重连
    }
}
```

**Pipe 高性能读取**（`System.IO.Pipelines`）：

```csharp
private async Task ReciveAllBytes(ClientWebSocket webSocket, PipeWriter writer)
{
    const int bufferSize = 4096;
    while (!cts.Token.IsCancellationRequested)
    {
        var memory = writer.GetMemory(bufferSize);  // 从 Pipe 分配内存
        var recived = await webSocket.ReceiveAsync(memory, cts.Token);

        if (recived.MessageType == WebSocketMessageType.Text)
        {
            writer.Advance(recived.Count);       // 标记已写入长度
            if (recived.EndOfMessage) break;     // 消息结束
        }

        if (recived.MessageType == WebSocketMessageType.Close)
        {
            await webSocket.CloseOutputAsync(...);
            break;
        }

        var result = await writer.FlushAsync();  // 标记为可读
        if (result.IsCompleted) break;
    }
    await writer.CompleteAsync();
}
```

## 六、跨平台适配：麒麟 V10 四层防御体系

### 6.1 问题背景

在银河麒麟 V10 上长时间运行时，.NET JIT 编译器在 Linux 的 `memfd:doublemapper` 内存映射区域发生段错误（segfault），导致进程崩溃。所有崩溃堆栈均指向 JIT 编译后的代码在 doublemapper 区域执行时触发。

### 6.2 运行时层：禁用 doublemapper + 崩溃 dump

```csharp

[STAThread]

{
    // ① 启用崩溃 dump 收集
    AppContext.SetData("DOTNET_DbgEnableMiniDump", 1);
    AppContext.SetData("DOTNET_DbgMiniDumpType", 4);  // Full dump
    AppContext.SetData("DOTNET_DbgMiniDumpName",
        $"/opt/pcitech/mics/bin/crash/{DateTime.Now:yyyyMMddHHmmssfff}.dmp");

    if (RuntimeInformation.IsOSPlatform(OSPlatform.Linux))
    {
        // ② 允许生成 dump (PR_SET_DUMPABLE)

        Environment.SetEnvironmentVariable("DOTNET_LinuxDoubleMapping", "0");

        Environment.SetEnvironmentVariable("DOTNET_GCHeapHardLimit", "0x200000000");

}
```

### 9.4 BaseDAO：自动故障转移 + 连接状态缓存

```csharp
// Server/MicsClient.Server.ORM/BaseDAO.cs

public abstract class BaseDAO : IDisposable
{
    // 静态缓存：连接串 → 最近联通状态
    private static readonly ConcurrentDictionary<string, (bool Success, DateTime Time)>
        dbConnStatusCache = new();
    // 静态缓存：配置key → DBInfo
    private static readonly ConcurrentDictionary<string, DBInfo> dbConfigCache = new();
    private static readonly Timer retryTimer;

    static BaseDAO()
    {
        Dapper.DefaultTypeMap.MatchNamesWithUnderscores = true;
        // 5秒间隔重试失败连接
        retryTimer = new Timer(_ => RetryFailedConnections(), null, 5000, 5000);
    }

    // 初始化：优先连接 → 逐一尝试 → 自动故障转移
    protected void Init()
    {
        var dbinfos = config.GetSection("MicsConfig:DbConfig").Get<List<DBInfo>>();

        // 优先连接（如历史库、NOCC 库）
        if (preferConf != null && GetLastConnStatus(preferConf.ConnectString).Success)
        {
            try { TestConnDb(preferConf); return; }
            catch { /* 优先库不可达，继续尝试 */ }
        }

        // 按 OrderNo 顺序逐一尝试
        foreach (var item in dbConfigInfos.OrderBy(t => t.OrderNo))
        {
            if (!GetLastConnStatus(item.ConnectString).Success)
                continue;  // 缓存标记为失败的，跳过
            try
            {
                TestConnDb(item);
                ConnStatus = ConnStatus.Connected;
                return;   // 连接成功
            }
            catch { continue; }
        }
    }

    // 后台定时重试失败连接
    private static void RetryFailedConnections()
    {
        foreach (var kv in dbConnStatusCache.Where(kv => !kv.Value.Success))
        {
            if (dbConfigCache.TryGetValue(kv.Key, out var dbInfo))
            {
                try
                {
                    var da = DAFacadeFactory.CreateDAFacade(type, connStr, timeout);
                    da.Connection.Open();
                    da.Connection.Close();
                    dbConnStatusCache[dbInfo.ConnectString] = (true, DateTime.Now);
                }
                catch
                {
                    dbConnStatusCache[dbInfo.ConnectString] = (false, DateTime.Now);
                }
            }
        }
    }
}
```

## 十、总结：各模块技术关键词

| 职责 | 核心技术 | 关键设计模式 |
|------|---------|-------------|
| 跨平台迁移 | .NET 10, Avalonia UI, 双入口分离 | 平台抽象 + DI 注入 |
| YARP 反向代理 | ASP.NET Core Kestrel, YARP, 路由分流 | 请求头注入 + 健康检查 |
| ZeroC ICE | ICE RPC, 回调注册, ObjectAdapter | 多主机故障转移 + Polly 重试 |
| WebSocket 双通道 | System.IO.Pipelines, Channel, Polly | 主题订阅 Pub/Sub + MessagePack |
| CEF 混合渲染 | CefGlue, Minimal API, LocalWebSocket | Decorator 动态替换 + 请求头桥接 |
| 跨平台适配 | DOTNET_LinuxDoubleMapping, prctl | 四层防御体系 |
| 平台原生服务 | P/Invoke, X11/Xinerama, IPP/CUPS | 策略模式 |
| 报警管理 | ICE Callback → Channel → WebSocket | 生产者-消费者 + 内存缓存 |
| 数据库访问 | Dapper, DAFacade, DAFacadeFactory | Facade 模式 + 简单工厂 + 自动故障转移 |
