# 简历 — 项目介绍

---

## 城市轨道交通综合监控系统（MICS）客户端工作站

**项目周期：** 2024.01 — 至今
**项目角色：** 核心开发 / 技术负责人
**团队规模：** 15 人

### 项目简介

该项目是面向地铁/城轨运营场景的综合监控（ISCS）客户端工作站软件，为 OCC（运营控制中心）调度员和车站值班员提供统一的监控、报警、设备控制和运营管理平台。系统对接 BAS（楼宇自控）、CCTV（视频监控）、PA（公共广播）、PIS（乘客信息系统）、SIG（信号系统）等多个地铁子系统，支持多线路、多车站、多屏工作站的运营监控场景。

### 核心职责

- 负责客户端整体技术架构设计与技术选型，主导从 .NET 8 / WPF 向 **.NET 10 / Avalonia UI** 的跨平台迁移，实现 Windows 与国产操作系统（银河麒麟 V10 UKUI）双平台统一运行
- 设计并实现客户端内嵌 **YARP 反向代理**架构，统一管理多车站后端路由、健康检查与请求头加密注入，实现客户端对多站点服务的透明访问
- 基于 **ZeroC ICE** 中间件设计与实现后端通信层，包括服务发现、多主机故障转移、回调注册、心跳保活等核心机制，保障实时数据的可靠传输
- 主导 **WebSocket 双通道**通信架构设计：客户端侧采用 System.IO.Pipelines + Polly 弹性重试 + MessagePack 二进制序列化实现高吞吐低延迟数据通道；服务端侧实现基于主题订阅的 Pub/Sub 模型，桥接原生 UI 与内嵌 H5 页面
- 设计并实现 **CEF（Chromium）混合渲染**方案，通过 `CefView` 控件实现原生 Avalonia 视图与 Web 组态画面的无缝切换，配合 LocalWebSocket + Minimal API 构建 Native↔H5 双向通信桥
- 主导**跨平台适配**工作，针对银河麒麟 V10 的 JIT doublemapper 段错误问题，构建数据层→绑定层→运行时→生命周期四层防御体系，解决长时间运行崩溃问题
- 设计**平台原生服务抽象层**（策略模式），实现截屏（Win32/X11+Xinerama）、打印（Shell Verb/IPP+CUPS）等功能的跨平台适配
- 负责报警管理模块全链路设计与优化，实现 ICE 回调→Channel 生产者-消费者→WebSocket 推送的端到端数据流，并通过内存缓存、范围过滤、跨站 YARP 代理等手段优化性能
- 主导数据库访问层设计，基于 **Dapper** 构建 Facade 模式封装，支持 MySQL/Oracle/SQL Server/PostgreSQL/达梦等 7 种数据库适配与自动故障转移

### 技术亮点

| 领域 | 技术方案 |
|------|---------|
| **运行时** | .NET 10，支持 ReadyToRun 预编译与 TieredPGO 优化 |
| **UI 框架** | Avalonia UI 11.3.9 + CommunityToolkit.Mvvm（源码生成 MVVM） |
| **混合渲染** | CEF（CefGlue v120）嵌入 Chromium，原生/Web 双模式无缝切换 |
| **通信中间件** | ZeroC ICE RPC + 回调机制，Polly 弹性重试 |
| **内嵌代理** | ASP.NET Core Kestrel + YARP 反向代理，多站路由与健康检查 |
| **实时通信** | WebSocket 双通道 + System.IO.Pipelines + MessagePack 二进制协议 |
| **数据访问** | Dapper 微型 ORM，Facade 模式，7 种数据库适配 |
| **视频集成** | LibVLC 视频播放 + PTZ 云台控制 + 电视墙多分割 |
| **跨平台** | Win32/X11 P/Invoke 原生互操作，IPP/CUPS 打印协议 |
| **安全** | DES 加密传输、SHA256 请求追踪、单实例互斥锁、角色权限控制 |
| **高可用** | ICE 多主机故障转移、AB 网冗余切换、多屏同步、WebSocket 自动重连 |
| **日志** | NLog 结构化日志，SQL/通信日志独立分类，模块级自动归档 |

### 业务成果

- 系统成功部署于多条地铁线路的 OCC 控制中心及各车站工作站，覆盖 XDZ、OCC 等多种运营场景
- 实现 Windows 与银河麒麟 V10 双平台统一运行，满足轨道交通行业国产化替代要求
- 支持多线路、多车站、双屏工作站的复杂运营监控场景，日均处理报警数据数万条
- 通过 YARP 代理架构统一了客户端对 12+ 台后端服务器的访问路径，简化了网络配置与运维复杂度
- 报警自动推图、CCTV 联动弹窗等功能显著提升了运营人员的应急响应效率
