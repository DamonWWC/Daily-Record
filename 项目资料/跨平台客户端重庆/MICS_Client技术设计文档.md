# MICS Client 技术设计文档

> **项目名称**：城市轨道交通综合监控系统（MICS）客户端工作站  
> **版本**：5.0.2  
> **技术栈**：C# / .NET 10 / Avalonia UI / CefGlue (Chromium) / YARP / ASP.NET Core / ZeroC ICE / WebSocket / Dapper  
> **目标平台**：Windows / 银河麒麟 V10 SP1 UKUI

---

           │

    │           │
   YES          NO
    │           │
    ▼           │
尝试优先库       │
    │           │

    │
    ▼

## 八、技术栈总览

| 领域 | 技术方案 |
|------|---------|
| **运行时** | .NET 10（ReadyToRun + TieredPGO） |
| **UI 框架** | Avalonia UI 11.3.9 + CommunityToolkit.Mvvm |
| **混合渲染** | CefGlue.Avalonia (Chromium 120) |
| **反向代理** | ASP.NET Core Kestrel + YARP 2.3.0 |
| **RPC 中间件** | ZeroC ICE（回调 + 服务发现 + 多主机故障转移） |
| **实时通信** | WebSocket + System.IO.Pipelines + MessagePack |
| **弹性策略** | Polly v8（线性/指数退避 + 无限重试） |
| **数据访问** | Dapper + Facade 模式（7 种数据库） |
| **视频集成** | LibVLCSharp.Avalonia 3.9.4 |
| **跨平台互操作** | P/Invoke (X11/Xinerama/CUPS) + SharpIpp |
| **日志** | NLog 6.0.6（三通道分离 + 模块自动归类） |
| **安全** | DES 加密 + SHA256 签名 + 单实例互斥锁 |
| **设计模式** | 策略/工厂/外观/模板方法/中介者/发布订阅/生产者消费者 |
