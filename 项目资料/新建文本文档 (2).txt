4、综合监控国产化项目
项目描述：面向地铁运营场景的综合监控跨平台客户端软件，基于.NET10+Avalonia框架，可在Windows和Linux桌面系统上运行。为运营控制中心调度员与车站值班员提供统一的监控、报警、设备控制和运营管理平台。系统对接BAS、CCTV、PA、PIS、SIG
等多个地铁子系统，支持多线路、多车站、多屏工作站的运营监控场景。
技术栈：C# / .NET 10 / Avalonia UI / CefGlue (Chromium) / YARP / ASP.NET Core / ZeroC ICE / WebSocket / System.IO.Pipelines / Polly / Dapper / MessagePack / LibVLCSharp / NLog
岗位职责：
1、参与客户端整体技术架构设计与技术选型，负责从.NET Framework/WPF向.NET10/Avalonia UI的跨平台迁移，实现Windows与国产操作系统（麒麟系统）双平台统一运行。
2、主导 WebSocket 双通道通信架构设计：客户端侧采用 System.IO.Pipelines + Polly 弹性重试 + MessagePack 二进制序列化实现高吞吐低延迟数据通道；服务端侧实现基于主题订阅的 Pub/Sub 模型，桥接原生 UI 与内嵌 H5 页面
3、设计并实现 CEF（Chromium）混合渲染方案，通过 CefView 控件实现原生 Avalonia 视图与 Web 组态画面的无缝切换，配合 LocalWebSocket + Minimal API 构建 Native↔H5 双向通信桥
4、负责报警管理模块全链路设计与优化，实现 ICE 回调→Channel 生产者-消费者→WebSocket 推送的端到端数据流，并通过内存缓存、范围过滤、跨站 YARP 代理等手段优化性能
