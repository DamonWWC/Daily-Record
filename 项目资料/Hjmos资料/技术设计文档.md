## 1. 项目概述

### 1.1 业务背景

智慧地铁管控平台是面向地铁运营调度员的桌面应用，提供车站全息感知、应急指挥、视频监控、设备监控、数据看板等核心功能。系统 7×24 小时运行，面向多工作站部署。

### 8.3 权限过滤机制（位运算）

```
RegionType 枚举 (Flags):
┌───────────┬──────────┐
│ 线网 = 1  │ 0b 001   │
│ 线路 = 2  │ 0b 010   │
│ 车站 = 4  │ 0b 100   │
│ All  = 7  │ 0b 111   │
└───────────┴──────────┘

用户角色 → RegionType 映射:
  RoleType = 1 (线网管理员) → RegionType.线网 (1)
  RoleType = 2 (线路调度员) → RegionType.线路 (2)
  RoleType = 3 (车站值班员) → RegionType.车站 (4)

过滤逻辑: (menu.Region & userRegion) == userRegion

示例 — 线路调度员 (userRegion = 2):
┌──────────────────┬──────────────┬──────────────────────┬──────────┐
│ 菜单             │ menu.Region  │ & userRegion (2)     │ 是否显示 │
├──────────────────┼──────────────┼──────────────────────┼──────────┤

│ 应急处置(车站级) │ 车站 (4)     │ 4 & 2 = 0 ✗         │ ❌ 隐藏  │

│ 数据看板         │ 线路|车站(6) │ 6 & 2 = 2 ✓         │ ✅ 显示  │
```

## 18. 技术风险与缓解

| 风险项 | 影响等级 | 描述 | 缓解措施 |
|--------|---------|------|----------|
| CefSharp 内存占用 | 高 | 每个 H5 面板占用 100-300MB | 限制同时打开的 H5 面板数量；使用磁盘缓存 |
| WebSocket 连接断开 | 中 | 心跳超时或网络波动导致断连 | 295 秒心跳 + 3 次×5 秒重连 |
| Token 过期 | 中 | Token 过期后所有 API 失败 | 提前 5 分钟刷新 + 401 自动重试 |
| Unity 焦点抢占 | 中 | 3D 嵌入导致 WPF 快捷键失效 | 300ms 焦点轮询 + WM_ACTIVATE 管理 |
| 模块 DLL 加载失败 | 低 | 模块 DLL 缺失或版本不匹配 | try-catch 保护 GetModuleType，返回 null |
| 视图缓存内存增长 | 中 | Region 缓存视图不被 GC 回收 | 提供 DeleteView 方法主动清理 |
| 视频快速切换泄漏 | 中 | 快速切换摄像头 MediaPlayer 累积 | Rx Throttle(1s) + Switch() 去抖取消 |
| 异常导致应用退出 | 高 | 未捕获异常导致 7×24 系统中断 | 三层全局异常捕获 + Handled=true |
| REST API 异常吞没 | 低 | RestApi 永不抛异常，问题被隐藏 | LogHelper.Error() 记录所有失败 |
| 配置项分散 | 低 | 70+ 配置项在两个 XML 文件中 | 统一 AddressConfigEnum 枚举管理 |
