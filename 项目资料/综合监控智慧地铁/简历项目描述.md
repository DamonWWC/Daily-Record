# 简历项目描述 —— 智慧车站综合监控客户端（IOMS Client v3.0）

## 项目简介

面向城市轨道交通（地铁）智慧车站与智慧安防场景的企业级 WPF 桌面客户端应用。项目基于 C#/.NET Framework 4.7.2 开发，采用 MVVM 架构，集成 Unity 3D 数字孪生、多协议视频监控、实时报警联动、Web 内容嵌入等技术栈，涵盖智慧车站、智慧安防、智慧维保三大业务域，覆盖 80+ 功能页面模块。系统服务于成都（17/18/19号线）、宁波（7号线）、济南（6号线）、深圳、广州等多条地铁线路的综合监控与运营管理，由 6 人核心团队持续迭代近 5 年，累计 860+ 次版本提交。

## 技术栈

C# / .NET Framework 4.7.2 / WPF / MVVM / LibVLC / FFmpeg（Direct3D11 硬件加速） / Unity 3D / CefSharp（Chromium） / TCP&WebSocket / MQTT / HTTP/2&3 / NLog / System.Reactive / Stateless 状态机 / FluentFTP / NSIS

## 核心职责与成果

### 一、视频监控与分析系统（核心模块）

- 基于 LibVLC/LibVLCSharp 自研多分屏视频播放控件体系，支持 1/4/9/16 多路分屏、全屏切换、视频分组管理、视频收藏、轮播巡视及录像回放等功能，覆盖实时视频监控与安防视频分析两大业务场景
- 设计并实现视频树资源管理组件，支持按线路、车站、区域等多层级展示摄像头资源，实现视频资源的快速检索与拖拽分配
- 针对多路视频并发播放场景进行深度性能优化，通过改进渲染管线与解码调度策略，有效解决视频失帧、卡顿等问题，显著提升播放流畅性
- 对接 MediaAgent 视频云平台控制接口，封装 HTTP2/HTTP3/WebExAPI 多版本通信协议适配层，实现 PTZ 云台控制、预置位管理、视频流地址动态获取等功能
- 开发视频分析预警弹窗模块，支持实时预警信息展示、未处理预警查看、预警确认与误报标记，并实现预警视频的全屏播放与跳转联动

### 二、报警联动与应急管理体系

- 开发多类型报警管理模块（火灾报警、汛情报警、设备故障报警、自定义任务报警、站台门报警、电梯乘客求助等），实现报警实时推送、分类过滤、统计展示与一键确认机制
- 将报警处理逻辑抽象抽离为统一的 AlarmHelper，重构报警相关 ViewModel，提升代码可维护性和扩展性；实现报警接收时间与发生时间超过 5 分钟自动丢弃的时效性过滤策略
- 设计并实现报警→3D 数字孪生联动机制：双击报警栏自动触发 Unity 三维场景全屏聚焦，定位到报警设备空间位置，同步弹出关联视频监控画面，形成"报警—定位—视频确认"的闭环应急响应链路
- 开发防火分区报警规程与消防联动功能，实现相同防火分区类型去重报警、预案执行跟踪、设备房动态切换及预案并发冲突防护

### 三、Unity 3D 数字孪生集成

- 实现 Unity 3D 引擎嵌入式集成方案，通过自研 PESocket（TCP/WebSocket）通信库与 Unity 进程进行指令交互，完成车站三维场景可视化、模型设备点击定位、设备信息浮窗展示等核心交互
- 开发三维模型联动指令体系，包括设备定位指令、视频巡检模式进入/退出指令、全屏/取消全屏指令、模型联动循环控制等，实现客户端与三维场景的双向实时通信
- 实现设备关联视频联动功能：点击三维场景中的设备模型或图标，自动调用 MediaAgent 接口获取关联视频流并弹出播放窗口，支持汛情视频、报警视频等多种联动场景

### 四、智慧车站运营功能

- 开发一键开关站功能模块，实现扶梯、卷帘门、屏扇门等设备的批量控制下发与执行状态回传，支持执行过程中的视频弹窗监控、步骤暂停恢复及异常记录处理
- 实现汛情监测与分析模块，包括防汛视频弹窗、汛情历史记录、关键位置视频巡检等功能，通过配置项（IsShowFloodGroupVideoView 等）控制不同线路的差异化展示
- 开发视频巡检模块，支持机房巡检、屏前巡检、关键位置自动巡视等多种巡检模式，实现巡检任务管理、巡检记录、巡检过程中与三维场景的模式切换联动
- 参与客流监测与预测、能源管理（PSCADA 电力监控）、环境控制模式、智慧照明、设备管家等多个车站运营管理子模块的前端对接与联调

### 五、平台架构与工程化建设

- 参与设计基于 Git 多分支策略 + XML 配置化开关的多线路定制交付方案：主线维护公共核心代码，各线路分支通过功能配置项（20+ 定制开关）和菜单配置 XML（MenuConfig_HT/WB/TFZ/CTG 等）实现差异化功能裁剪，支撑 7+ 条线路的并行定制与独立交付
- 设计并实现多级菜单系统架构，支持菜单层级动态配置、菜单权限按角色控制（RoleId）、菜单启动/禁用配置项等，满足各线路差异化的功能入口需求
- 开发 FTP 自动更新系统（IOMS.UpdateManager），支持加密配置文件、断点续传、进度展示、客户端与三维模块分别更新、更新程序自身自更新等机制；配套编写单元测试保障更新逻辑可靠性
- 搭建自动化编译打包流程，包括 Compile.bat 批量编译脚本、MD5/SHA256 校验生成、NSIS 安装包脚本与 WinRAR 归档，实现一键构建发布
- 集成 CefSharp（Chromium Embedded Framework）实现 Web 内容嵌入方案，支持前端 H5 页面与 WPF 客户端的双向通信（JS Bridge），实现视频播放控制、DevTool 调试、缓存管理等桥接功能
- 实现英文版本国际化适配，完成智慧车站客户端的多语言支持与界面本地化
