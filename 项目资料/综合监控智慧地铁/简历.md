1、综合监控智慧地铁项目
项目描述：面向城市轨道交通智慧车站与智慧安防场景的大型WPF桌面客户端，基于.NET Framework 4.7.2与MVVM架构，集成Unity 3D数字孪生、LibVLC多协议视频监控、实时报警联动、CefSharp Web嵌入等技术栈，覆盖智慧车站/安防/维保三大业务域80+功能模块，服务于成都、宁波、济南、深圳、广州等多条地铁线路的综合监控与运营。
技术栈：C# / WPF / MVVM / LibVLC / FFmpeg / Unity 3D / CefSharp / TCP&WebSocket / MQTT / HTTP/2&3 / NLog
岗位职责：
1、重构LibVLC多路并发渲染管线，解决失帧卡顿；封装MediaAgent多协议适配层，标准化PTZ云台控制与视频流调度。
2、从零学习Unity 3D并承担数字孪生模块开发，基于自研PESocket实现客户端与三维进程双向指令交互，完成报警触发、设备定位、视频巡检等联动功能；持续优化通信稳定性与场景响应性能，打通"报警→3D定位→视频弹出"闭环联动链路。
3、优化一键开关站批量控制与多模式视频巡检；完善汛情监测与视频联动；参与PSCADA等子系统接口优化与性能调优。
4、设计Git多分支+XML配置化多线路交付方案；开发FTP自动更新系统，搭建编译、校验、打包一键构建流程，提升版本迭代效率。
