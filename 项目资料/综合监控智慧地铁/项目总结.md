# Mics3.0_IOMS_Client 项目总结

## 项目定位

**IOMS.Client (Integrated Operations Management System Client v3.0)** 是一套面向**城市轨道交通（地铁）智慧车站与智慧安防**的大型 WPF 桌面客户端应用程序。项目基于 **.NET Framework 4.7.2**，采用 **C# + WPF + MVVM** 架构开发，集成 Unity 3D 数字孪生、LibVLC/FFmpeg 视频播放、CefSharp 浏览器内嵌、PESocket/MQTT 通信等多种技术栈，服务于全国**多条地铁线路**的综合监控与运营管理场景。

## 核心功能体系

### 1. 视频监控与分析（第一大核心功能）
- 基于 LibVLC/LibVLCSharp 的多分屏、全屏、分组视频播放
- 视频巡检（机房、屏前、关键位置自动巡视）
- 安防视频分析与实时弹窗
- 摄像头 PTZ 云台控制、预置位管理、录像回放
- 设备关联视频（点击 3D 模型设备即弹出关联视频流）
- 支持 HTTP2/HTTP3/WebExAPI 多版本 MediaAgent 通信协议
- 自研 FFmpeg 播放器库 FlyleafLib（Direct3D11 硬件加速渲染）

### 2. 报警管理体系
- 多类型报警：火灾报警、汛情报警、自定义任务报警、设备故障报警
- 报警栏实时展示、过滤、统计与确认
- 报警→3D 定位联动（双击报警自动聚焦到 3D 场景中的设备）
- 报警→视频联动（弹窗显示关联视频）
- 5 分钟自动丢弃规则
- 报警处理逻辑抽象为 `AlarmHelper` 统一管理

### 3. 火灾应急与预案联动
- 防火分区巡检与设备房动态切换
- 火灾处置预案菜单，联动 3D 模型指令
- 应急预案执行跟踪、历史记录
- WebJS 集成控制预案任务的启动与停止
- 预案并发冲突防护机制

### 4. Unity 3D 数字孪生
- 车站三维场景可视化
- 点击模型设备定位、视频联动
- 3D 全屏切换与视频巡检模式
- 通过 PESocket 发送模型联动指令
- Unity 模块管理器集中管理 3D 激活与定位逻辑

### 5. 智慧车站运营
- **一键开关站**（扶梯、卷帘门、设备批量控制）
- **汛情监测与分析**（防汛视频弹窗、历史记录）
- **机电/机房/自由巡检**（任务管理、巡检记录）
- **客流监测与预测**（实时客流、历史客流、客流疏导）
- **能源管理、环境管理、智能调光、智慧厕所**
- **电力监控（PSCADA）**
- **施工管理、运营管理、报表台账**
- **气象灾害、电梯/扶梯运维**
- **人员考勤与定位**

### 6. 智慧安防
- 门禁系统（ACS）管理
- 周界报警
- 安防事件管理与信息发布
- 安防视频分析、站台门监控

### 7. 自动更新系统
- 基于 FTP 的客户端自更新（IOMS.UpdateManager）
- 加密配置文件、断点续传、进度展示
- 支持客户端模块与 3D 模块分别更新
- 一键打包脚本（NSIS + WinRAR）

## 多线路定制策略

项目通过**分支策略**实现多条地铁线路的并行开发与定制：

| 线路 | 分支 | 提交量 | 定制标识 |
|------|------|--------|----------|
| 成都 17/18/19号线 | `Dev_CDLine` 系列 | ~144 | `【CD】` |
| 宁波 7号线 | `Dev_NBLine` | ~41 | `【NBL7】` |
| 济南 6号线 | `Dev_JNLine` | ~27 | `【JNL6】` |
| 深圳鸿蒙线 | `Dev_SZHM` | ~35 | `【深圳鸿蒙】` |
| 深大城际 | `Dev_SDCJ` | ~15 | `【深大城际】` |
| 大连线 | `Dev_DLLine` | — | — |
| 英文版 | `Client_EN` / `SmartClient_En` | — | — |

主线（`master`）维护公共核心代码，各线路分支通过**配置项开关**（如 `IsShowFloodGroupVideoView`、`IsPlayDeviceAssociatedVideo` 等）和**菜单配置 XML**（`MenuConfig_HT/WB/TFZ/CTG.xml`）实现差异化功能裁剪。

## 总结

这是一个**持续演进近 5 年、服务于全国多条地铁线路**的企业级智能车站综合监控客户端。它以**视频监控**和**报警联动**为核心，结合 **Unity 3D 数字孪生**实现空间化的设备管理与应急响应，涵盖智慧车站、智慧安防、智慧维保三大业务域 80+ 功能模块，通过灵活的多分支策略和配置化定制支撑不同地铁客户的差异化需求。
